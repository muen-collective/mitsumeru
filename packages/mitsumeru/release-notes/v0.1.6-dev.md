Internal build — carries the `-dev` suffix; the update channel it belongs to is
`dev`.

**The accent picker is gone.** `@muen/dsh-mitsumeru-appearance` no longer ships.
It wrote the `--dsw-*` brand roles (`brand-primary`, `button-primary-hover`,
`button-primary-dimmed`, `interactive-bg-hover`, `interactive-bg-active`), and a
theme plugin now wants those same tokens — so shipping both meant two layers
competing per-token with mount order deciding the winner. The Settings → General
section no longer has an Accent row. This is a step back to decide the design,
not a removed feature: nothing about the token engine changed, only whether it is
composed.

**Installing over 0.1.5-dev removes it from your profile by itself.** That needed
more than taking it out of the shipped list, which is worth knowing because the
first attempt did not work: the app keeps any bundle that is not base and not
shipped, since that is exactly how a plugin *you* added survives an update. A
package we drop looks identical to that. There is now an explicit retired list, so
the appearance plugin is actively removed while anything you installed yourself is
kept.

**A redesigned loading screen.** `//starting mitsumeru` with a blinking red
rectangle, and `stare intently at the void...` beneath it, on a pure black field —
set from the design frame rather than approximated. Each line's size and
letter-spacing were solved against the frame's measured ink, so it renders within
a pixel of the artwork: `//` is white, red is only the caret, and the caret is a
fixed 6×10 rectangle rather than a full x-height block.

Wraps DeepSeek Harness 0.1.5-rc.1 — unchanged, including the DeepSeek 4.1 model
adapter.

Signed with Developer ID, notarized by Apple, stapled. Gates: `pnpm verify:release`,
`pnpm verify:surfaces`, and the packaged-app smokes.

Install: download `Mitsumeru-0.1.6-dev-arm64.dmg`. An installed 0.1.5-dev offers
this version by itself.
