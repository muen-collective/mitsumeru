Internal build — carries the `-dev` suffix; the update channel it belongs to is
`dev`.

**The light theme was rebuilt.** EVA 00 is now a blue theme rather than a teal
one, with the colours taken from the Figma swatches:

| | |
|---|---|
| buttons, icons, the active tab | `000864` |
| the label inside a filled button | `00C4FF` |
| links and inline code | `2b5fa8` |
| body text | `0c0f3c` |

The surfaces lost their cyan cast at the same time — they were biased blue-green
on every step, which is part of why the app read as teal even where the accents
were not.

**Inline code is coloured again.** Monospaced text in a sentence — a file path,
a filename — had been rendering as ordinary body text inside a box. It now takes
the same colour as links, so the two read as the same family: mint in dark, blue
in light.

**The brand dot follows the app.** The dot in the Mitsumeru mark used to be a
fixed cyan. It now takes the design source's colours — orange-red on dark, red on
light — and follows the *theme you picked*, not the operating system's appearance.
That distinction matters: picking EVA 01 on a light-mode Mac used to leave the dot
showing the wrong colour.

**Two hover bugs, both found by using it.** A filled button's label could take
the same colour as the fill underneath it and disappear entirely — in the light
theme, contrast 1.00. Fixed, and there is now a check that reads the generated
themes and refuses to build if any colour pair is unreadable or if an interactive
state is identical to its resting state. That check is what caught the second
one.

Wraps DeepSeek Harness 0.1.5-rc.1 — unchanged, including the DeepSeek 4.1 model
adapter.

Signed with Developer ID, notarized by Apple, stapled. Gates: `pnpm verify:release`,
`pnpm verify:surfaces`, `pnpm verify:mount` — which boots a real window and reads
the Theme row, both skins and every colour back out of a live renderer, so
"present but not mounted" or "configured but not applied" cannot pass as success.

Install: download `Mitsumeru-0.1.8-dev-arm64.dmg`. An installed 0.1.7-dev offers
this version by itself.
