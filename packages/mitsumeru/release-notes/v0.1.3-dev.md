Internal build — carries the `-dev` suffix; the update channel it belongs to is
`dev`.

The first build to carry the brand surfaces. The published 0.1.2-dev was built
just before them, so no download has shown the app icon on Apple's icon grid,
the dmg window with the lockup and tagline, the loading screen with the mark, or
a window title that stays `Mitsumeru`. This release is that gap closed.

Wraps DeepSeek Harness 0.1.5-alpha.2 as the published npm closure.

Signed with Developer ID, notarized by Apple, stapled. Gate: `pnpm verify:release`,
plus the packaged-app smokes (smoke, smoke:native, smoke:updater).

Install: download `Mitsumeru-0.1.3-dev-arm64.dmg`. An installed 0.1.2-dev offers
this version by itself.
