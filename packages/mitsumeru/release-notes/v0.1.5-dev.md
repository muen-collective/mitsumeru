Internal build — carries the `-dev` suffix; the update channel it belongs to is
`dev`.

**The sidebar is finally Mitsumeru's.** Every build until now showed the DeepSeek
whale in the top-left corner, and nothing was broken in any way a check could
see: the seat that holds that mark is exclusive, upstream ships its own occupant
for it, and ours was never in the list of things this app composes — so the
fallback won, and the app booted clean with somebody else's name on it. The brand
package now ships *and* composes: its first act is standing upstream's occupant
down, and its second is taking the seat. A new gate reads the mark back out of a
real renderer and fails when it is not ours, so this cannot go quiet again.

**The app icon is the right size.** The icon was drawn on Apple's own grid (0.805
of the canvas) while the app people are coming from used a full-bleed one, so
ours read as undersized sitting beside it in the Dock. It is now on Apple's grid
at 0.875 — what Safari, Music, Notes and Calculator use. The artwork is generated
by `pnpm icon` rather than being a hand-made file, so the next icon change is one
number, not another un-reproducible binary.

**The installer has no background image.** This was committed for 0.1.4-dev but
never reached a download: that disk image had been built before the change. This
one carries it — open the installer and you get a plain window with the app and
Applications in it, and nothing else.

**Installing over 0.1.4-dev fixes the sidebar by itself.** The app updates its own
profile on launch, so nothing needs deleting. Sessions, workspaces and accent
choices are untouched: the profile's files are updated in place rather than
replaced, and a plugin you installed yourself is kept.

**This version replaces one that could not start.** A 0.1.5-dev build was briefly
published and is withdrawn: it looked up its own plugins one directory too deep,
so no plugin was linked, and dsh refused to boot on a bundle that was present in
the tree but linked nowhere — a window that appears, then a failed boot. The check
that catches this (`pnpm smoke`) was not run before that build was published, and
was run before this one. If you happened to take that build, this installs over
it normally.

Wraps DeepSeek Harness 0.1.5-rc.1 — unchanged from 0.1.4-dev, including the
DeepSeek 4.1 model adapter.

Signed with Developer ID, notarized by Apple, stapled. Gates: `pnpm verify:release`,
`pnpm verify:surfaces`, and the packaged-app smokes (`smoke`, `smoke:finder`,
`smoke:native`, `smoke:updater`).

Install: download `Mitsumeru-0.1.5-dev-arm64.dmg`. An installed 0.1.4-dev offers
this version by itself.
