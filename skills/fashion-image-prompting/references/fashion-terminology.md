# Claire Fashion Terminology Reference

> Purpose: Give the LLM a concrete vocabulary of professional apparel and fashion design terms for accurate prompt generation. Inject relevant sections into the system prompt as context.

---

## Silhouettes & Dress Shapes

| Term | Definition |
|------|-----------|
| **A-line** | Fitted at the shoulders, gradually flares from the bust to hem (shaped like letter A) |
| **Empire waist** | High waistline just under the bust, flowing fabric below |
| **Sheath** | Form-fitting, straight-cut dress following body contours |
| **Shift** | Straight, unstructured dress hanging from shoulders (no waist definition) |
| **Trapeze** | Flares from shoulders in a trapezoid shape, wider than A-line |
| **Fit-and-flare** | Fitted bodice, flared skirt starting at natural waist |
| **Drop waist** | Waistline sits below natural waist (hip-level), often 1920s-inspired |
| **Peplum waist** | Short flared ruffle or overskirt attached at the waistline |
| **Mermaid / Trumpet** | Fitted through body, flares dramatically at or below knees |
| **Ball gown** | Fitted bodice, very full floor-length skirt |

## Necklines

| Term | Definition |
|------|-----------|
| **Crew neck** | Round, close-fitting neckline at base of neck |
| **V-neck** | V-shaped opening, can be shallow or deep |
| **Scoop neck** | Wide, deep U-shape exposing collarbone |
| **Boat neck / Bateau** | Wide horizontal neckline running from shoulder to shoulder |
| **Sweetheart** | Curved top resembling top of a heart, often strapless |
| **Halter** | Straps wrap behind the neck, leaving shoulders bare |
| **Cowl neck** | Draped, loose fabric at neckline forming soft folds |
| **Off-the-shoulder** | Exposes shoulders, fabric sits below them |
| **One-shoulder / Asymmetric** | One shoulder covered, other bare |
| **Keyhole** | Small cutout at front neckline, often with button or tie closure |
| **High neck / Turtleneck** | Covers neck, can be folded (turtleneck) or stand-up (mock neck) |

## Sleeves

| Term | Definition |
|------|-----------|
| **Set-in sleeve** | Sleeve sewn into armhole at natural shoulder line |
| **Raglan sleeve** | Sleeve extends to collar in one piece, diagonal seam from underarm to neck |
| **Dolman / Batwing** | Sleeve cut wide at armhole, narrowing to wrist — deep armhole, loose fit |
| **Cap sleeve** | Short sleeve barely covering shoulder cap |
| **Puff sleeve** | Gathered at shoulder and/or cuff creating volume |
| **Bishop sleeve** | Full sleeve gathered at wrist into a cuff |
| **Bell sleeve** | Flares from elbow to hem like a bell |
| **Juliet sleeve** | Long fitted sleeve with puff at top (Renaissance-inspired) |
| **3/4 sleeve** | Ends mid-forearm between elbow and wrist |
| **Bracelet sleeve** | Ends just above wrist, designed to show bracelets |
| **Wide cuff** | Sleeve ends in a broad, stiff band (often with buttons) |
| **Balloon sleeve** | Full sleeve gathered at both shoulder and wrist, ballooning in between |
| **Leg-of-mutton / Gigot** | Extremely full at shoulder, fitted from elbow down |

## Collars & Lapels

| Term | Definition |
|------|-----------|
| **Notch lapel** | V-shaped notch where lapel meets collar (standard suit jacket) |
| **Peak lapel** | Lapel points upward and outward (formal, tuxedo) |
| **Shawl collar** | Continuous curved collar without a notch (tuxedo, cardigan) |
| **Mandarin / Band collar** | Short stand-up collar, no fold (traditional Chinese) |
| **Peter Pan collar** | Flat, round-cornered collar (feminine, vintage) |
| **Sailor collar** | Square back collar with front V-neck (naval-inspired) |
| **Revere collar** | Open V-shaped lapel/collar (relaxed, no top button) |
| **Wing collar** | Small standing collar with folded-down wing tips (formal dress shirts) |
| **Detachable collar** | Separate stiff collar attached with studs (historical/vintage) |

## Waistlines & Bodice

| Term | Definition |
|------|-----------|
| **Natural waist** | Narrowest part of torso (at navel) |
| **Dropped waist** | Below natural waist, at hip level |
| **Princess seam** | Vertical seam running from shoulder/armhole through bust to hem (no waist seam) |
| **French dart** | Diagonal dart from side seam toward bust (more shaping than standard waist dart) |
| **Boning** | Stiff strips in bodice for structure (corsetry) |
| **Bustier** | Fitted, strapless bodice extending to waist |
| **Corset top** | Laced or boned bodice, waist-cinching |
| **Bias cut** | Fabric cut at 45° to grain — drapes and clings to curves |

## Skirts & Draping

| Term | Definition |
|------|-----------|
| **A-line skirt** | Fitted at waist, flares to hem |
| **Pencil skirt** | Straight, narrow, knee-length |
| **Pleated skirt** | Regular folds pressed into fabric |
| **Accordion pleat** | Narrow, uniform pleats (knife-sharp, all same direction) |
| **Box pleat** | Two folds facing opposite directions, meeting in center |
| **Godet** | Triangular fabric insert for flare (often at skirt hem) |
| **Wrap skirt** | Fabric wraps and ties at waist |
| **Tulip skirt** | Overlapping front panels like tulip petals |
| **Bubble hem** | Hem tucked under to create balloon-like volume |
| **Draped** | Fabric gathered or folded to create flowing asymmetry |
| **Ruching** | Fabric gathered in parallel rows (elastic or stitched) |
| **Asymmetric hem** | Uneven hemline (high-low, diagonal) |

## Pants & Bottoms

| Term | Definition |
|------|-----------|
| **Wide-leg** | Loose from hip to hem, full width |
| **Straight-leg** | Consistent width from thigh to ankle |
| **Tapered** | Narrower at ankle than thigh |
| **Cropped** | Ends above ankle (mid-calf to ankle) |
| **Culottes** | Wide-leg pants that resemble a skirt |
| **Palazzo** | Extremely wide-leg, full-length, flowing |
| **Cigarette** | Slim, straight, ankle-length |
| **Flared / Bell-bottom** | Fitted through thigh, flares from knee down |
| **Peg-top** | Full at hips, narrow at ankles |
| **Paper-bag waist** | Gathered waist with belt or tie, fabric blouses over |
| **Jodhpur** | Full through hip/thigh, fitted below knee (equestrian) |

## Jackets & Outerwear

| Term | Definition |
|------|-----------|
| **Blazer** | Tailored jacket, structured shoulders, open front |
| **Bolero** | Short cropped jacket, open front, often sleeve-only coverage |
| **Double-breasted** | Two parallel rows of buttons, overlapping front |
| **Single-breasted** | One row of buttons |
| **Peacoat** | Double-breasted wool coat, broad lapels, naval origin |
| **Trench coat** | Belted raincoat, epaulets, storm flaps, double-breasted |
| **Chesterfield** | Single-breasted overcoat, velvet collar, no waist seam |
| **Bomber / Flight jacket** | Ribbed collar, cuffs and hem, zip front |
| **Motorcycle / Biker jacket** | Asymmetric zip, wide lapels, metallic hardware |
| **Blouson** | Jacket gathered at waistband, blousing above |
| **Spencer jacket** | Short, waist-length, fitted (19th century) |
| **Zouave jacket** | Short bolero-style, often heavily embroidered |

## Details & Embellishments

| Term | Definition |
|------|-----------|
| **Aiguillettes** | Ornamental braided cord loops worn on shoulder (military) |
| **Epaulets** | Ornamental shoulder pieces (fringed, braided, or metallic) |
| **Frog closure** | Ornamental braided loop-and-knot fastening |
| **Passementerie** | Decorative trim: braids, tassels, fringes, cords |
| **Smocking** | Fabric gathered and embroidered in honeycomb pattern |
| **Pintucks** | Very narrow parallel stitched tucks |
| **Ribbon trim** | Satin or grosgrain ribbon sewn as border or accent |
| **Lace overlay** | Lace fabric layered over base fabric |
| **Appliqué** | Decorative fabric shapes sewn onto base fabric |
| **Beadwork / Beading** | Beads sewn in pattern |
| **Sequins** | Small shiny discs sewn individually or in rows |
| **Fringe** | Hanging threads or strips at hem/edge |
| **Scalloped edge** | Edge cut in repeating curves |
| **Rope braiding** | Twisted cord trim applied to edges (military/naval) |
| **Gold braiding / Galloon** | Metallic braid trim |
| **Brass buttons** | Gold-toned metal buttons, often embossed |
| **Covered buttons** | Buttons wrapped in same fabric as garment |

## Fabrics & Textures

| Term | Definition |
|------|-----------|
| **Silk charmeuse** | Lightweight satin-weave silk, glossy face, matte back |
| **Silk chiffon** | Sheer, lightweight, soft drape, slightly rough texture |
| **Silk crepe de chine** | Lightweight, matte, pebbly texture, excellent drape |
| **Silk dupioni** | Crisp, lustrous, irregular slubs, structured |
| **Silk organza** | Sheer, crisp, stiff, holds shape |
| **Silk taffeta** | Crisp, smooth, rustles (formal wear) |
| **Silk velvet** | Plush pile surface, deep color, luxurious |
| **Wool crepe** | Matte, pebbly texture, excellent drape |
| **Wool gabardine** | Tightly woven, diagonal twill rib, durable |
| **Wool melton** | Dense, felted, smooth surface (coats) |
| **Wool tweed** | Rough-textured, flecked yarn, traditional |
| **Cashmere** | Ultra-soft luxury wool from cashmere goats |
| **Cotton poplin** | Crisp, smooth, lightweight |
| **Cotton lawn** | Fine, soft, slightly crisp |
| **Cotton voile** | Sheer, lightweight, soft drape |
| **Cotton denim** | Twill weave, sturdy, diagonal rib |
| **Cotton twill** | Diagonal rib weave (chinos, jackets) |
| **Linen** | Flax fiber, crisp texture, wrinkles easily, breathable |
| **Leather (lambskin)** | Soft, supple, fine grain |
| **Leather (calfskin)** | Smooth, durable, medium grain |
| **Suede** | Napped finish on leather underside, soft, velvety |
| **Patent leather** | High-gloss coated leather |
| **Satin** | Glossy surface weave (can be silk, polyester) |
| **Lace** | Openwork fabric with patterned holes |
| **Brocade** | Richly figured woven fabric with raised patterns |
| **Jacquard** | Woven pattern (floral, geometric, damask) |
| **Sequin fabric** | Base fabric covered with sequins |
| **Mesh** | Open net-like woven or knitted fabric |

## Footwear

| Term | Definition |
|------|-----------|
| **Stiletto** | Thin, high heel (8+ cm) |
| **Kitten heel** | Short, slender heel (3-5 cm) |
| **Block heel** | Wide, chunky heel |
| **Cone heel** | Wide at top, narrows at bottom |
| **Wedge** | Solid heel running from back to middle of shoe |
| **Loafer** | Slip-on, low heel, often with decorative strap |
| **Oxford** | Lace-up, closed lacing (formal) |
| **Derby** | Lace-up, open lacing (less formal) |
| **Brogue** | Perforated decorative holes on leather |
| **Monk strap** | Buckled strap instead of laces |
| **Mary Jane** | Strap across instep, rounded toe |
| **Slingback** | Strap around back of heel, open back |
| **Mule** | Backless, closed or open toe |
| **Platform** | Thick sole under entire foot |
| **Ankle boot** | Boot ending at ankle |
| **Knee-high boot** | Boot reaching knee |
| **Over-the-knee** | Boot extending above knee |
| **Combat boot** | Lace-up, thick sole, military-inspired |
| **Chelsea boot** | Ankle-high, elastic side panels, pull-on |

- The LLM should reference these terms directly (not reproduce definitions)
- These terms represent the *minimum expected vocabulary* — the LLM should use them naturally
- If the LLM uses a term not in this list, it should be a legitimate fashion term, not a hallucination
